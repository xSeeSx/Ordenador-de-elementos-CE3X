# Ordenador de elementos CE3X 0.3.0

Nueva interfaz de ordenación por deslizamiento de filas. Los cerramientos se desplazan con sus elementos asociados, los grupos pueden plegarse y se muestra un espacio de inserción antes de soltar. Esc cancela; el motor impide cambiar asociaciones. Se mantienen botones, teclado, deshacer, rehacer y actualizaciones.

La herramienta sigue siendo experimental: comprueba el certificado resultante en CE3X. Descarga y extrae el ZIP completo en una carpeta nueva.
